# 🏠 Промпты для генерации фото объектов (раздел «Квартиры» в админке)

Промпты под **текущие объекты каталога** (5 проектов / 16 объектов из `005_demo_catalog.py`).
Фото объекта показываются на странице объекта в галерее «Фотографии и планировка».

**Технические требования:** горизонтальные **16:9**, минимум **1600×900**, форматы `.jpg/.png/.webp`, до 10 МБ.
Один набор можно **переиспользовать** для одинаковых планировок в разных проектах — грузите тот же файл в каждый объект.
**Как загрузить:** админка → объект → блок управления фото → загрузить.

> Промпты на английском — генераторы (Gemini / Midjourney / Flux / DALL·E) так дают лучший результат. Можно вставлять как есть.
